# Webブース予約

部屋（番号1〜8）を日付・時刻ごとに予約する Web アプリです。
画面は HTML / CSS / JavaScript だけで動くので、どの Web サイトにもそのまま置けます。
予約の保存先は `config.js` で切り替えます。

## ファイル構成

| ファイル | 役割 | 必須 |
|---|---|---|
| `index.html` `style.css` `app.js` | 画面と動作 | ○ |
| `config.js` | 保存先・教室などの設定（環境ごとに変えるのはここだけ） | ○ |
| `gas/Code.gs` | Googleスプレッドシートに保存する場合のスクリプト | GAS方式のみ |
| `api.php` `data/.htaccess` | サーバー上の CSV に保存する場合のプログラム | PHP方式のみ |

## 保存先の選び方

| 置き場所 | 設定 | 予約の共有 |
|---|---|---|
| GitHub Pages など静的サイト | GAS方式（`gasUrl` を設定） | ○ |
| PHP が動くサーバー | 何もしなくてよい（`auto` が api.php を自動で使う） | ○ |
| 上記以外・動作確認 | 何もしなくてよい | ×（各自のブラウザのみ） |

`backend: "auto"` のままなら、`gasUrl` → `api.php` → ブラウザ保存 の順に使えるものを自動で選びます。
今どれで動いているかは、画面左下に表示されます。

## GAS方式（Googleスプレッドシート）の準備

1. Googleスプレッドシートを新規作成する
2. 拡張機能 → Apps Script を開き、`gas/Code.gs` の内容を貼り付けて保存
3. デプロイ → 新しいデプロイ → 種類の選択で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 初回は権限の確認画面が出るので許可する
5. 表示された URL（`https://script.google.com/macros/s/…/exec`）を `config.js` の `gasUrl` に貼り付ける
6. 予約を1件入れて、スプレッドシートに `bookings` シートができていれば完了

Code.gs を修正したときは「デプロイを管理」→ 編集 → バージョン「新しいバージョン」で更新します（URL は変わりません）。

## PHP方式の準備

1. すべてのファイルをサーバーの公開フォルダに置く（隠しファイル `data/.htaccess` も）
2. `data` フォルダに Web サーバーの書き込み権限を付ける
3. ブラウザで `data/bookings.csv` を開き、表示されない（403）ことを確認
   - nginx では `.htaccess` が効かないので、設定で `data` へのアクセスを拒否する

## 別の環境へ移すとき

- 画面のファイルはそのままコピーするだけで動きます（パスはすべて相対パス）。
- 予約データは、どちらの方式も同じ列（`id,place,room,date,start,end,title,updated_at`）です。
  - スプレッドシート → CSV：ファイル → ダウンロード → CSV で `data/bookings.csv` として置く
  - CSV → スプレッドシート：`bookings` シートに CSV をインポート（列の書式は「書式なしテキスト」）

## 教室を増やすとき

`config.js` の `places` に追加すると、左上の選択ボックスに表示されます。
予約は教室ごとに分けて保存・表示されます。

```js
places: [
  { id: "331", name: "331教室" },
  { id: "332", name: "332教室" }
]
```

## 注意

URL を知っている人は誰でも予約の追加・削除ができます。
学外から見える場所に置く場合は、Basic 認証などでページを保護してください。
